# Admin Workspace Implementation Plan

**Goal:** Внедрить утверждённую админку Repa с работающими серверными методами.
**Architecture:** Filament CRUD и обычные Livewire страницы, бизнес-действия в
app/Actions, additive migrations и существующая авторизация.
**Spec:** docs/superpowers/specs/2026-10-12-admin-workspace-design.md

- [x] Интерфейс: design.md, единые CSS токены, навигация, простой ProductForm,
  облегчённая таблица товаров и рабочая главная с данными аналитики.
- [x] Склад: тесты ошибок/резервов/списаний, модели и миграции, InventoryManager,
  интеграция заказов и вариантов корзины, Livewire страница с историей.
- [x] Контент: тесты публикации/скрытия, статьи/страницы/баннеры/меню,
  админ-страницы, публичные контроллеры и подключение главной/навигации.
- [x] Аналитика: тесты периодов/конверсии, сбор собственных событий без PII,
  AnalyticsSummary и страница аналитики с реальными числами.
- [x] Интеграция: маршруты, обзор, обновление статуса проекта и self/code review;
  composer dump-autoload, optimize:clear, migrations, PHPUnit, Pint, Vite,
  проверка браузером реального интерфейса.

Ruling: существующий рабочий каталог сохраняется для работающего Docker bind mount;
новая ветка codex/admin-workspace создана от обновлённого origin/main. Уже сделанные
изменения характеристик семян сохранены в рабочем дереве как зависимость формы.
Ruling: внедрение выполняется без merge/deploy, через отдельную ветку проекта.

Проверка 12.10.2026: optimize:clear + полный PHPUnit — 181 тест, 621 assertions;
полный Pint --test — 186 файлов; Vite build — успешен; PostgreSQL migrate:status —
все миграции применены. Edge/Playwright проверил 6 экранов на 5 ширинах без
ошибок JS и корневого переполнения. Независимый review выявил два обхода склада;
оба устранены, повторный review и регрессионные тесты прошли.
Изменения оставлены в рабочем дереве codex/admin-workspace; коммит/push/PR не выполнялись.
